# ブログ記事のGitHub保存運用

## 公開前

- 記事本文、HTMLプレビュー、使用写真、生成・加工画像をGitHubへ保存する。
- ステータスは `draft`（公開前）とする。
- 既存のドラフトPull Requestで変更内容を確認する。
- 最終確認と公開判断はKojiが行う。

## 公開後

- 公開した日時、公開先URL、公開時に行った修正を変更履歴へ残す。
- サーバー上で直接修正した場合も、その内容をGitHubへ戻して記録する。
- GitHubと公開サーバーの内容が食い違わないようにする。

## 写真

- 記事で使用した元写真と加工後の写真を保存する。
- 人物が写る写真は、公開前に顔・目元のぼかしを確認する。
- 写真の撮影場所や料理名が不確かな場合は、確認事項として明記する。
