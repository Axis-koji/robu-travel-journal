プライバシーポリシー

ろぶーの気になる事（以下「当サービス」）は、訪問者の個人情報保護を最優先で扱います。

1. 取得する情報

  • 閲覧ログ（IPアドレス、ブラウザ情報、日時）
  • 投稿・コメント欄の入力情報（必要な範囲）
  • 言語設定（ブラウザ設定）

2. 利用目的

  • サイトの表示最適化と不具合修正
  • 分析による利便性向上
  • お問い合わせ対応
  • セキュリティ監視と不正利用防止

3. API 利用の事前許可

当サイトでは、外部 API を使用する操作については、実行前に事前許可が必要です。許可は各ユーザーの端末ローカルに保存され、同意なく外部 API を新規実行しません。

4. 第三者提供

法令に基づく場合を除き、当サービスは個人情報を第三者へ提供しません。

5. 保有と削除

保持期間は、取得目的を達成するのに必要な範囲で定め、必要がなくなれば適切に削除します。

6. お問い合わせ

ご不明点はサイト内の運営者情報（運営者名）までご連絡ください。

7. 改定

本方針は必要に応じて更新されます。改定時は本ページをもって公開します。
