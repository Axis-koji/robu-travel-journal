2. 約2420万画素フルサイズとDIGIC X、ISO 100〜102400で広がる表現

画質の土台になるのが、有効約2420万画素のフルサイズCMOSセンサーと、画像処理エンジンのDIGIC Xです。常用ISO感度は100〜102400と幅が広く、明るい屋外から暗めの室内まで、場面に合わせて感度を選べます。

約2420万画素は、SNSでの共有、家族アルバム、プリントまで幅広く使いやすい画素数です。フルサイズならではの余裕のある描写は、背景をやわらかくぼかした人物写真や、旅先の広がりのある風景を撮るときに楽しみが増します。

3. 登録人物優先と被写体検出で、家族もペットも乗り物も追いやすい

EOS R8 Mark IIの大きな進化がAFです。Dual Pixel CMOS AF IIを搭載し、EOS R8より主被写体への追従が改善されています。

注目したいのは、登録人物優先です。静止画と動画の両方に対応しています。あらかじめ登録した人物を優先してAFが追ってくれるので、人混みの中のわが子、集合写真の中の大切な人を撮りたいときに頼もしい機能です。人物は瞳、顔、頭部、胴体を検出するので、向きや距離が変わる場面でも主役を捉えやすくなります。

被写体検出は人物にとどまりません。動物は犬、猫、鳥、馬、乗り物はモータースポーツ、鉄道、飛行機の検出に対応しています。散歩中の愛犬、庭に来た野鳥、駅に入ってくる電車、空港で見上げる飛行機。ジャンルを切り替えながら被写体を追えるので、趣味の幅を広げたい人にも向いています。

4. 電子シャッター毎秒約40コマで、動きのある一瞬を狙える

電子シャッターでは、最高約40コマ/秒の連続撮影ができます。1秒間に40枚という速さは、ほんの一瞬の表情や動きを逃したくないときの強い味方です。

走り出す子どもの笑顔、ボールに飛びつく犬、羽ばたく鳥、カーブを抜ける電車。こうした動きのある場面で、前項のAFと組み合わせることで「この瞬間」を狙いやすくなります。連写で撮った中から、いちばん表情のよい一枚を選ぶ時間も、撮影の楽しみのひとつです。

運動会や公園遊び、ペットとの遊びの時間など、日常の動きものにたっぷり活躍してくれそうです。軽いボディで、カメラを構え続ける負担が少ないのも、動きを追う場面では効いてきます。

5. 6Kオーバーサンプリングの4K/60Pと、動画づくりの自由度

動画は、6Kオーバーサンプリングによる高精細な4K/60Pが大きな魅力です。6K相当の情報から4Kを生成するため、細部まで緻密な映像が期待できます。60Pなら動きもなめらかで、旅の風景、子どもの運動、ペットの動きがいきいきと残せます。

動画制作を楽しみたい人には、Canon Log 3とLook File／LUTの対応も嬉しい点です。撮影後に色を作り込む楽しさがあり、自分の映像の雰囲気を育てていけます。動画電子ISには「強＋」があり、歩きながらの撮影で手ブレ補正を重視したいときに頼れます。

さらに、美肌動画、レビュー用動画、手ブレ補正動画といった撮影モードが用意され、180PのフルHDやスロー＆ファストモーションにも対応しています。ゆっくり見せたい瞬間、テンポよく見せたい場面など、表現の幅が広がります。商品レビューやVlog、家族の記録まで、1台でこなせる柔軟さがあります。

6. 夜景カラーとフィルター、操作と通信まで、撮るのが楽しくなる工夫

EOS R8 Mark IIには、撮る時間そのものを楽しくしてくれる機能も揃っています。

ひとつが手持ち夜景モードのカラー設定です。Standard、Blue、Black&Orange、Pink、Greenの5色が用意され、夜の街の雰囲気を自分好みに仕上げられます。さらに、静止画用カラーフィルターのうち14種類は動画用LUTとして無料配布され、写真でも動画でも色づくりを楽しめます。

操作面では、8方向のマルチコントローラーを搭載しています。前面のタリーランプは動画撮影の状態を知らせてくれるので、撮られる側にも撮影中かどうかが伝わります。マルチアクセサリーシューで、アクセサリーを追加して撮影スタイルを広げていくこともできます。

通信は、5GHz Wi-FiとBluetoothに対応しています。撮った写真をスマートフォンへ送って共有する流れもスムーズにできるので、旅先でその日のうちに写真を見せ合う楽しみにもつながります。
