鉄道玩具の青いレールに、今度は飛行機が走ります。タカラトミーは2026年10月1日、「プラレールエアー 空をぐるっと！ ANA旅客機セット」を発売しました。希望小売価格は8,800円、対象年齢は3歳以上です。[1][2]

この玩具の面白さは、ただ平らな輪を走ることではありません。離陸で車輪が引っ込み、カーブでは機体を傾け、着陸で車輪が再び出る。その一連の動きを、立体コースの上で楽しめます。[1][2] 本稿は実機を遊んだレビューではなく、公式の発売資料と製品ページを基に仕組みと仕様を整理したものです。

先に結論：離着陸と旋回の動きが主役

このセットの魅力は、旅客機をただ手で転がすだけでなく、上昇・下降レールと高架の曲線レールを使い、離陸、傾いて旋回、着陸を連続した遊びにしたことです。飛行機、動力ユニット、専用レール、ターミナル駅、橋脚、マップシートまで入るオールインワン構成なので、初日から空港の場面を作れます。[1][2]

一方、通常のプラレール車両がすべての専用レールを走れるわけではありません。公式ページは、上昇・下降レール、エアー曲線レール、エアーストップレールをプラレール車両が走行できないと明記しています。[2] 「既存レールの完全互換拡張」ではなく、飛行機用の新しい遊びを既存の街へ足す製品と考えるのが正確です。

1. 価格と基本仕様

希望小売価格は8,800円（税込）。2026年10月1日発売で、対象年齢は3歳以上です。商品サイズは約幅410×奥行115×高さ310mm、単3形アルカリ乾電池2本を使い、電池は別売りです。[1]

対象年齢の表示は、一人で組み立てられるという意味ではありません。初回は大人が説明書を確認しながら、橋脚や電池の扱いを手伝うと安心です。タカラトミーは取扱説明書の検索窓口を設けています。[4]

この「商品サイズ」は、完成レイアウト全体の設置面積とは別です。公式の発展レイアウト例は約幅1330×奥行820×高さ190mmを示しています。[2] 同じ配置を作るとは限りませんが、床や机に十分な面積が必要な玩具だと分かります。購入前に遊ぶ場所と、片付ける箱や棚を決めておく方が安全です。

2. 飛んで見える仕組み

飛行機は専用のレールに沿って走ります。ポイントは、同じ高さで周回する輪ではなく、上昇・下降レールと橋脚で高さを変えた立体コースです。低い位置から上がり、曲線部を抜けて下りるため、離着陸の場面に流れが生まれます。[1][2]

本物の自由飛行やラジコンではありません。コースが動きを案内するので、小さな子どもにも飛行場面を繰り返し再現しやすい一方、行き先を自由に操縦する玩具とは遊び方が違います。

3. タイヤの昇降と旋回ギミック

公式資料は、離陸時にタイヤが格納され、着陸時に再び出る動きと、カーブで機体が傾く旋回を特長に挙げています。とくに、曲がるときに水平のまま滑るのではなく、機体がバンクするところが、この製品らしい見どころです。[1][2]

動きは、公式の離陸時のタイヤ収納写真と旋回時の機体の傾きの写真で確認できます。いずれもタカラトミーのページへ移動するリンクです。

4. 箱に入っているもの

セットには、ANA旅客機のボディ、飛行機動力ユニット、第1ターミナル駅、直線レール1本、エアー曲線レール8本、上昇・下降レール2本、エアーストップレール1本、レールホルダー12個、2倍ブロック橋脚6個、マップシート、シールが含まれます。[2]

飛行機、走行部、レール、支え、空港情景が一箱にそろうため、別売り部品がないと基本の飛行機遊びが始められない構成ではありません。ただし電池は別です。開封日に遊びたいなら単3形アルカリ乾電池2本も用意します。[1]

5. 既存のプラレール・トミカとの組み合わせ

付属のマップシートや別売りのプラレール車両、トミカを使い、空港へ向かう電車や街の車を一緒に配置できます。[1] ターミナル駅は「駅とターミナルが一つになった」情景部品として紹介されています。[2]

ここでの互換性は、同じ世界を作れるという意味です。飛行機用の専用カーブを電車が走れるという意味ではありません。手持ちの車両やミニカーを一緒に置く場合は、さらに面積が要ります。

ろぶーの結論

「プラレールエアー 空をぐるっと！ ANA旅客機セット」は、鉄道レールの規格をそのまま広げる製品ではなく、飛行機の離着陸と旋回をレール遊びへ持ち込んだ新しい枝です。8,800円で、立体的な飛行ルートと空港の情景をまとめて遊べる点が特徴です。

国内向けはANAとのコラボモデルです。[1] 一方、タカラトミーは、赤色のオリジナル機体を使うアジア版を、中国、香港、台湾、マレーシア、シンガポール、タイなどで順次展開予定としています。[1] ANA版の海外販売予定を示す発表ではないため、海外の販売ページを見る場合は国内版と取り違えないようにします。

ただし、専用レールの制約、設置面積、別売り電池は先に知っておくべきです。実機の作動音や耐久性を確認できるなら、店頭展示や信頼できる実演動画を見てから決めると、プレゼント後の「思っていた遊び方と違う」を減らせます。
