# ろぶーのきになる事

旅、乗り物、ベトナム、グルメを中心に、現地で役立つ情報をまとめるブログです。

公開サイトは GitHub Pages を利用します。

## フォルダ構成

- `index.html` — 表紙と記事一覧
- `privacy-policy.html` — プライバシーポリシー
- `articles/` — 記事原稿
- `assets/images/` — 表紙、カテゴリー、記事、Coming soonの画像

画像は外部サイトへ直接依存せず、原則として `assets/images/` に保存します。
